# PaperAI

## Overview
PaperAI predicts off-spec paper production during grade transitions using machine learning and provides AI-powered recommendations.

## Features
- Off-Spec Prediction
- Risk Score
- Corrective Recommendations
- Gemini AI Explanation
- Analytics Dashboard
- Correlation Heatmap
- Feature Importance
- Operator Feedback Logging
- Downloadable Report

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- Plotly
- Google Gemini
